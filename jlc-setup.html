嘉立创校对 · 油猴安装

必须更新到 ≥1.16.20：磁盘更新 不等于 Tampermonkey 已加载。
关键：只开 mh 首页「已登录」不够。必须打开 nw.jlcerp.com/smtbaseservice 贴片机机器库页，浏览器才会下发 SMT_ERP_SESSION_ID；否则 ERP 一直显示会话失效(460)。
已在机器库页仍 460 → 退出再登录，勿反复新开标签。
打开 nw 被跳到 mh 属正常；不要开库位 materialLocation（私有库提货仅 API 查库位）。同站点勿 Chrome+Edge 双开。
  1. 点「安装/更新」→ Tampermonkey 确认。
  2. 点「打开机器库页」；FAB 显示 JLC桥 v1.16.20 且在线。
  3. 回 ERP「嘉立创校对」应显示油猴在线，可连扫下载；面板有「查客编库存 / 填提货申请」。
